# Where is my car Unity 2D spēle
##Galvenais mērķis
Spēles galvenais mērķis ir aizvilkt katru mašīnu uz viņas vietu un pareizi viņu ievietot. Kamēr mašīna tiek vilkta, ir jāuzmanās no dažādiem šķēršļiem, kuri lido garām.

##Spēles taustiņu darbības
**Z** - pagriezt mašīnu pa kreisi / pretpulksteņrādītājvirzienā
**X** - pagriezt mašīnu pa labi / pulksteņrādītājvirzienā
**Atstarpe** - apgriezt mašīnu otrādi
**→** - izstiept mašīnu
**←** - saspiest mašīnu
