# Where is my car Unity 2D spēle
## Galvenais mērķis
Spēles galvenais mērķis ir **aizvilkt un pareizi ievietot katru mašīnu viņas vietā**.

<img width="728" height="407.5" alt="image" src="https://github.com/user-attachments/assets/b86abb82-0539-473e-a919-5464379e3d3e" />

Kamēr mašīna tiek vilkta, ir **jāuzmanās no dažādiem šķēršļiem**, kuri lido garām.

<img width="728" height="407" alt="image" src="https://github.com/user-attachments/assets/b89b2fb5-2673-410a-a49e-b79a1ec1f17d" />

Šķēršļus ir iespējams iznīcināt ar bumbu palīdzību. Novietojot kursoru uz bumbas, tā uzsprāgst un iznīcina **visus objektus** tās apkārtnē.

## Spēles taustiņu darbības
**Z** - pagriezt mašīnu pa kreisi / pretpulksteņrādītājvirzienā \
**X** - pagriezt mašīnu pa labi / pulksteņrādītājvirzienā\
**Atstarpe** - apgriezt mašīnu otrādi\
**→** - izstiept mašīnu\
**←** - saspiest mašīnu
